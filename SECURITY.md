# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub Security Advisories using **Report a vulnerability**:

<https://github.com/mirdax25-ux/DEHAL/security/advisories/new>

Do not disclose a vulnerability in a public issue. We will acknowledge a report within 72 hours.

## Supported versions

The current package version, `2.1.2` (declared in `pyproject.toml`), is supported. Earlier versions are not currently supported.
